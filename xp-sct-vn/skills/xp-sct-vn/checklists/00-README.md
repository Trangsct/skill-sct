# Khung kiểm tra theo lĩnh vực — cách dùng

Mỗi checklist = bảng 5 cột: **Nội dung kiểm tra → Căn cứ nghĩa vụ → Tài liệu/hiện trạng cần xem → Hành vi nếu vi phạm (điểm-khoản-điều nghị định xử phạt) → XỬ (Sở) / CHUYỂN (cơ quan)**. Chép đầu mục vào mục 3.2 Kế hoạch kiểm tra (Mẫu 02) và mục 4.3 Biên bản kiểm tra (Mẫu 05). Đánh dấu ĐẠT / CHƯA ĐẠT / KHÔNG XUẤT TRÌNH / KHÔNG ÁP DỤNG.

Cột "Hành vi" chỉ ghi điều khoản đã có bản gốc (NĐ 275/2026); các nghị định khác ghi số nghị định + ⚠️ (tra bản gốc trước khi ghi vào biên bản VPHC). Chi tiết kỹ thuật từng lĩnh vực nằm ở plugin nghiệp vụ tương ứng.
